# Group Web Development Project

A collaborative web development project built as part of a team to design and develop a functional and responsive website. This project demonstrates teamwork, frontend development skills, and real-world project structure.

## Features
- Responsive web design (mobile-friendly)
- Interactive UI components
- Structured multi-page layout
- Clean and user-friendly interface
- Team-based development workflow

## Technologies Used
- HTML5
- CSS3
- JavaScript

## 👥 Team Collaboration
- Worked in a group environment using Git & GitHub
- Managed version control and code integration
- Divided tasks among team members (UI, logic, testing)

## Learning Outcomes
Real-world team collaboration
Version control using Git
Building responsive web interfaces
Debugging and integrating team code
