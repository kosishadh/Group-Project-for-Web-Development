Template Validation Report

As the Template Lead, I verified the core layout structure shared across all pages. The global header, navigation system, and footer were tested for structural integrity and ARIA landmark compliance. The validation confirm that the responsive container system and sticky navigation do not interfere with HTML5 parsing rules.

Home Page Validation Report

The Home Page passed the W3C markup validation with no errors. The semantic structure using <main>, <header>, and <section> landmarks was correctly identified. One minor warning regarding the use of a section without a heading was resolved by adding a screen-reader-only heading for the statistics strip. The use of custom properties in the CSS did not affect HTML validity.

Gallery Page Validation Report

Validation for the Gallery Page initially flagged two missing alt attributes on dynamically generated thumbnails. These were corrected in the JavaScript template literal. The final validation check shows a clean report. The custom font customisation controls were verified to use standards-compliant data-* attributes for event handling, ensuring the markup remains valid while providing interactive functionality.

Content Page Validation Report

The Content Page (Climate Science Explained) adheres strictly to HTML5 standards. Validation confirmed the correct nesting of <article> and <section> tags. The sidebar navigation was validated as a proper <aside> landmark. All ARIA labels for the smooth-scrolling anchors were verified for accessibility compliance. No validation errors or warnings remain in the final build.
